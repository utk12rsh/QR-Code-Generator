# QR Code Generator – .NET Core 9.0 Mini Project 🚀

A simple and handy **QR Code Generator** built using **.NET Core 9.0**.  
This project allows users to generate QR codes from text or URLs and download them in PDF format.

---

## Features ✅

- Enter any text or URL to instantly generate a QR Code.  
- Download the generated QR Code as a **PDF file**.  
- Responsive and user-friendly interface.  
- Built using **.NET Core 9.0**, **QRCoder Library**, and **iTextSharp 5** for PDF generation.  

---

## Technologies Used 🛠️

- **ASP.NET Core 9.0** – Backend framework  
- **QRCoder** – Generate QR codes  
- **iTextSharp 5** – Generate PDF files  
- **HTML / CSS / JavaScript / jQuery** – Frontend and UI interactions  

---

## How to Use 🚀

1. Clone or download the repository.  
2. Open the project in **Visual Studio 2022** or any compatible IDE.  
3. Restore NuGet packages:  
   - `QRCoder`  
   - `iTextSharp`  
4. Run the project.  
5. In the web page:  
   - Enter text or URL into the input field.  
   - Click **Generate QR Code**.  
   - Use **Download PDF** to save the QR code as a PDF file.
